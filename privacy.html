プライバシーポリシー

「30代会社員のお金研究所」(以下「当ブログ」)は、訪問者のプライバシーを尊重し、以下の方針で運営しています。

広告の配信について

当ブログでは、第三者配信の広告サービス「Google AdSense」を利用しています(導入後)。Googleを含む第三者配信事業者は、Cookieを使用して、ユーザーが当ブログや他のウェブサイトに過去にアクセスした際の情報に基づいて広告を配信します。

Googleが広告Cookieを使用することにより、ユーザーが当ブログや他のサイトにアクセスした際の情報に基づいて、Googleやそのパートナーが適切な広告をユーザーに表示できます。ユーザーは広告設定でパーソナライズ広告を無効にできます。詳しくはGoogleの広告に関するポリシーをご確認ください。

アフィリエイトプログラムについて

当ブログは、楽天アフィリエイト、A8.netなどのアフィリエイトプログラムに参加しています。記事内のリンクを経由して商品・サービスが購入・申込みされた場合、当ブログに報酬が発生することがあります。広告を含む記事には【PR】と表記しています。報酬の有無によって、記事の内容や商品の評価を変えることはありません。

アクセス解析について

当ブログは、Bloggerが提供する閲覧統計機能を利用しています。これらはCookie等でアクセス情報を収集することがありますが、個人を特定する情報は含まれません。Cookieはブラウザの設定で無効にできます。

コメントについて

コメント欄に入力された名前等の情報は、コメントの表示・管理の目的でのみ利用します。個人情報の入力はお控えください。

免責事項

当ブログの情報は、できる限り正確な記載に努めていますが、内容の正確性・安全性を保証するものではありません。商品の価格・仕様・サービス内容は変更される場合がありますので、最新情報は必ず公式サイト・販売ページでご確認ください。当ブログの情報を利用して生じた損害について、責任を負いかねます。

著作権

当ブログの文章・画像の著作権は運営者に帰属します。無断での転載・複製はお控えください。引用の際は出典として当ブログへのリンクを明記してください。

Googleユーザーデータの取り扱い(アプリ「30代マネーラボ Blogger連携」)

当ブログの運営者は、記事の投稿・管理のために、Google OAuth を使う個人用ツール「30代マネーラボ Blogger連携」(以下「本アプリ」)を利用しています。本アプリが利用するのは、運営者本人のGoogleアカウントのデータだけです。

1. アクセスするデータ

  • Blogger(https://www.googleapis.com/auth/blogger):運営者のブログの情報、記事・固定ページの作成・更新・読み取り

2. データの使い方

当ブログへの記事・固定ページの投稿と更新だけに使います。広告配信、データの販売、汎用的なAI・機械学習モデルの学習には使いません。

3. 共有・転送・開示

Googleユーザーデータを第三者に販売しません。また、法令に基づく開示を求められた場合を除き、第三者に共有・転送・開示しません。データのやり取りはGoogleのAPIとの間だけで行います。

4. データの保護

通信はすべてHTTPS(TLS)で暗号化します。認証情報(OAuthトークン・クライアントシークレット)は運営者のパソコン内で管理し、公開・送信しません。

5. 保持と削除

本アプリが保存するのは、OAuthトークンと、作業に必要な記録(投稿した記事のID・URL・タイトルなど)です。作業記録は運営に必要な間だけ保持し、本アプリの利用をやめるときにトークンとあわせて削除します。アクセス権は Google アカウントの「サードパーティのアプリとサービス」(https://myaccount.google.com/connections)からいつでも取り消せます。取り消すとトークンは無効になります。

6. Google API サービスのユーザーデータに関するポリシー

本アプリが Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

TikTokユーザーデータの取り扱い(アプリ「ClaudeCode Auto Poster」)

当ブログの運営者は、自分で制作した短尺動画を自分のTikTokアカウントへ投稿するために、TikTok for Developers の Content Posting API を使う個人用ツール「ClaudeCode Auto Poster」(以下「本アプリ」)を利用しています。本アプリを使うのは運営者本人だけで、一般の方のTikTokアカウントにはアクセスしません。

1. アクセスするデータ

  • 運営者本人のTikTokアカウントの基本情報(表示名・アカウントID)
  • 運営者本人のアカウントへ動画を投稿するための権限(Content Posting API)

2. データの使い方

運営者本人が作った動画を、運営者本人のアカウントへ投稿するためだけに使います。広告配信、データの販売、AIモデルの学習には使いません。

3. 共有・開示

TikTokから取得したデータを第三者に販売・共有・開示しません。法令に基づく開示を求められた場合を除きます。

4. データの保護と削除

通信はHTTPS(TLS)で暗号化します。認証情報(アクセストークン・クライアントシークレット)は運営者のパソコン内で管理し、公開しません。本アプリの利用をやめるときは、保存したトークンを削除します。アクセス権はTikTokアプリの「設定とプライバシー」→「セキュリティとアカウントのアクセス許可」→「連携アプリ」からいつでも取り消せます。

5. AI生成コンテンツ

投稿する動画にはAIで生成した人物(キャラクター)が含まれる場合があります。その場合はTikTokの「AI生成コンテンツ」ラベルを付け、広告を含む動画には【PR】と表記します。

English summary

TikTok user data (app: "ClaudeCode Auto Poster"). This is a personal tool used only by the blog owner. It uses the TikTok Content Posting API to upload short videos created by the owner to the owner's own TikTok account only. Data accessed: basic profile info (display name, account ID) of the owner's own account and permission to post videos to it. Use: only to post the owner's own videos. Not used for advertising, not sold, not used to train AI models. Sharing: not sold, shared or disclosed to third parties except where required by law. Protection and deletion: all traffic uses HTTPS; tokens stay on the owner's computer and are deleted when the app is no longer used. Access can be revoked at any time in the TikTok app under Settings and privacy > Security & permissions > Apps and services. AI-generated content: videos may include AI-generated characters and are labeled as AI-generated content; ads are marked with PR.
